Clair — приложение для заметок и задач для Mac и Android. Эта политика объясняет, какие данные обрабатывает Clair, где они хранятся и как их удалить.

Где хранятся данные

На устройстве. Заметки, задачи, списки, папки, вложения и история разговоров с ассистентом хранятся локально в хранилище приложения. Ключ ИИ-провайдера хранится в защищённом хранилище системы — связке ключей macOS или Android Keystore.

В вашем Google Диске (по желанию). Если вы войдёте в Google в настройках синхронизации, Clair сохраняет копию данных в скрытой папке приложения в вашем Google Диске, чтобы они были на всех ваших устройствах. Эта папка принадлежит вашему аккаунту; разработчик к ней доступа не имеет.

Данные Google

Clair запрашивает единственное разрешение — drive.appdata: доступ только к собственной скрытой папке приложения в вашем Google Диске. Clair не видит другие ваши файлы, почту, контакты и любые иные данные Google.

Данные, полученные через API Google, используются только для хранения и синхронизации ваших собственных данных Clair между вашими устройствами. Они не передаются третьим лицам, не используются для рекламы и не используются для обучения моделей ИИ. Использование и передача Clair информации, полученной от API Google, соответствуют Политике в отношении пользовательских данных сервисов API Google, включая требования ограниченного использования (Limited Use).

ИИ-функции

ИИ-функции (ассистент, правка текста, план дня, поиск по смыслу) необязательны и работают только с ключом ИИ-провайдера, который вы вводите сами (например, OpenRouter или ваш собственный сервер). Когда вы пользуетесь ими, текст запроса и нужные для ответа фрагменты ваших заметок и задач отправляются напрямую с вашего устройства выбранному вами провайдеру — не через разработчика. Обработку этих данных провайдером регулирует его собственная политика конфиденциальности.

Поиск по смыслу включается отдельно и с предупреждением: при включении текст каждой заметки отправляется провайдеру для вычисления векторов поиска.

Как удалить данные

  • Отдельные заметки и задачи — удалите в приложении и очистите корзину.
  • Данные на устройстве — удалите приложение.
  • Копию в Google Диске — в Google Диске откройте «Настройки → Управление приложениями», найдите Clair и выберите «Удалить скрытые данные приложения». Доступ Clair к аккаунту можно отозвать на странице myaccount.google.com/permissions.

Дети

Clair не предназначен специально для детей и сознательно не собирает данные детей.
